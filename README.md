# SKBN 左中右・編輯器

## 🆕 這次新增：素材自動比對＋自動陰影／自動配色

匯入工單 Excel 之前，先點右上角「上傳素材資料夾(zip)」，把美術丟圖區那包
zip（例如 `924-930.zip`）整包丟進來，再匯入 Excel，系統會自動：

1. **商品自動加陰影**：Excel「曝品」欄寫「商品」的才會自動開陰影、方向固定
   往右；寫「素材」（商城券樣圖等）不會自動加陰影。
2. **LOGO 自動裁切＋白底**：匯入的 LOGO 一律自動套用「裁切+白底」模式
   （PNG固定白底、JPG自動取樣四角顏色當底色，這個處理本來就有，只是匯入
   時會自動打開，不用再手動切換）。
3. **素材自動比對，找不到才警示**：LOGO/商品圖檔名，先比對你剛上傳的這批
   資料夾，比對不到再查 `data/asset-library.json` 資料庫（常用LOGO、券樣
   模板等），兩邊都沒有的項目，會在畫面最上面列出警示清單，不會擋住其他
   已經比對到的格子。比對邏輯是模糊比對：忽略空白/底線/大小寫/副檔名/
   「Copy of」「複製」這類重複檔名前後綴。
4. **中間版位/檔期限定LOGO**：像「10.10品牌週年慶\01_LOGO」這種寫法，系統
   會辨識成「內建代碼」，直接查資料庫的 `matchKeys`，不會去你上傳的資料夾
   裡找檔名（見 `data/asset-library.json`）。
5. **券樣素材疊字**：Excel「曝品=素材」時，實際的券種（商城券*1/*2、免運車）
   跟疊字（$200/20%/94折）寫在下面那一列，系統會套資料庫裡的空白券圖模板，
   再把文字疊在券圖留白區（位置是抓的合理預設值，`modules/product-module.js`
   的 `_drawMaterialText` 裡的 0.64/0.52 兩個比例數字可以再調）。
6. **背景色自動配色**：Excel 背景色寫「不指定」時，系統會同時看 LOGO 跟商品
   的主色，取視覺上比較搶眼(飽和度較高)的那個當基準色相，背景會用同色相但
   刻意跟主體明暗拉開的顏色（不會吃色）；主標文字顏色也會跟著配成同色系但
   保證看得清楚的深/淺版本。這兩個顏色都可以在放大編輯面板手動覆蓋。

**目前資料庫裡還缺兩張圖**（工單裡有寫到，但這批資料夾跟資料庫都還沒有），
路徑已經先登記好，之後把圖丟進去就會自動生效，不用改任何程式或JSON：
```
system-elements/site-wide-sale/1010anniversary_logo.png   10.10品牌週年慶 中間橫版LOGO
system-elements/site-wide-sale/0925_logo_white-no-usp.png 9.25檔期 中間橫版LOGO(白字/無USP)
system-elements/site-wide-sale/mall_free-shipping-cart.png 商城免運車圖示（放artwork/site-wide-sale/，見下方路徑）
```
（最後一個實際路徑是 `artwork/site-wide-sale/mall_free-shipping-cart.png`，
不是 `system-elements/`，因為它是「素材/曝品」不是LOGO。）

在補圖之前，這三個項目會一直出現在警示清單裡，這是正常的，不影響其他格子。

## 🆕 這次新增：匯入彈窗（Excel + 資料夾）＋ 主標文字字數/禁用語檢查

跟你的 krcb 專案同一套UX：

- 點右上角「匯入工單」會跳出一個彈窗，裡面兩個 dropzone：Excel 工單、
  素材資料夾。兩個都可以「點擊選擇」或「直接拖曳」，素材那一格拖曳
  **整個資料夾**或**一個zip檔**都吃（自動判斷），選好後按「確認匯入」，
  跑的還是同一套自動比對流程，不用再分兩顆按鈕、兩次操作。
- 放大編輯任一版位，右側面板最上面會顯示「主標文字」的即時字數計燈
  （超過Excel「字數」欄設定的上限會亮紅燈）跟禁用語提示（有安全的建議
  替換字時會出現「套用」按鈕，一鍵改掉不用自己重打）。文字本身還是直接
  在畫布上點字編輯，這個面板只是唯讀的即時檢查回饋。
- 字數規則：英數/符號算0.5個字、中文字算1個字，用這份工單全部17個主標
  文字逐一驗算過，跟Excel「字數」欄完全對得上。
- 禁用語清單（`data/banwords.json`）直接沿用你 krcb 專案那份蝦皮文案規範
  （避免"最強/最便宜"這類最高級用語、中文數字要改阿拉伯數字、金額格式
  規則等），你之後要調整規則，直接編輯這份json就好，不用改程式。

## 怎麼打開
建議不要用瀏覽器直接雙擊 `editor.html`。因為「從資料庫選擇」功能要讀取
`data/asset-library.json`，瀏覽器對 `file://` 開啟的頁面通常會擋掉這種本機
檔案讀取（其他功能不受影響，只有資料庫下拉選單會是空的）。

用一個最簡單的本機伺服器打開即可，例如在這個資料夾內執行：

```
python3 -m http.server 8000
```

然後瀏覽器開 `http://localhost:8000/editor.html`。

## 版型說明

畫面／輸出都是同一份規格：**一張 1200×360 白底畫布，左中右三張各自導 35px
圓角的卡片**疊在白底上面（不是切三等份，卡片位置/尺寸各自不同），完全比照
你提供的 CSS 量出來的座標，寫在 `configs/skbn-layout.js`：

- 左／中／右卡片：各自的位置、尺寸、圓角、預設底色
- 每張卡片內的 LOGO／CTA／掛標／曝品／主標文字 各自的座標（中間的LOGO位置
  比較寬，就是你說的「橫LOGO」，邏輯完全一樣、只是zone尺寸不同，不用特判）
- 掛標（tagZone）現在左／右兩張卡片都有；中間目前沒有，是照你目前給的座標
  範圍——之後如果中間也要掛標，提供座標，我補進這份設定檔就會自動出現
- 主標文字固定 40px 粗體、無陰影（`titleFontPx`/`titleFontWeight`，如果你說
  的「40pt」其實是印刷pt=53.3px，改這兩個數字就好）
- 卡片內各元素的疊放順序是：底色 → LOGO/掛標 → 商品圖 → CTA → 主標文字
  （CTA 一定在商品圖上面，主標文字一定在最上層），這個順序在畫面預覽跟
  匯出的PNG是一致的

## 掛標／CTA：全站共用固定素材

這兩個都不是依品牌/檔期挑選的資料庫素材，是「全站共用」的固定圖，但兩者
規則不一樣：

**掛標**：白色版／紅色版兩種，依這一格背景色的深淺自動決定用哪版（深色背景
→ 白版才有對比；淺色背景 → 紅版），也可以在放大編輯面板的「掛標」分頁裡
手動覆蓋成「自動／白／紅／關」。亮度判斷門檻是
`configs/shared-elements.js` 裡的 `SHARED_ELEMENTS.luminanceThreshold`
（預設0.4），要調整多深算「深色」改這個數字就好。

**CTA**：只有一種版本（固定黑色圓底＋一張圖示），不分深淺、不用切換、也不
能關掉——每一格都會固定顯示，放大編輯面板的CTA區塊只是說明文字，沒有任何
可調整的選項。

圖檔實際放在 `system-elements/shared/`，檔名要對到
`configs/shared-elements.js` 裡寫的路徑：

```
system-elements/shared/tag-white.png   掛標白色版
system-elements/shared/tag-red.png     掛標紅色版
system-elements/shared/cta.png         CTA（只有這一張，固定版本）
```

**這三個檔案你還沒上傳**，資料夾裡目前只有一份 README 說明；掛標會顯示
「掛標（尚未上傳白/紅版）」文字佔位，CTA 會顯示純黑色圓底（沒有圖示，
不是壞掉）。等你把圖丟進去、檔名對上，就會自動生效，不用改任何程式或設定。

## 放大編輯視窗

點卡片右下角「放大編輯」，會開一個置中的浮動視窗（不是滿版，可以看到後面
主畫面），分三欄：

- **左欄**：物件切換（商品圖／LOGO／掛標，掛標只有這一格有tagZone才會出現），
  各自的上傳/移除/資料庫選擇按鈕
- **中間**：這張卡片的放大預覽，主標文字可以直接點擊輸入；商品圖可以直接
  拖曳移動、拖右上角白色控制點縮放（選取範圍是橘色虛線框，只框住圖片裡
  真正有色的內容，不含PNG四周的透明留白）；開了商品影子的話，畫面上會多
  一個灰色小圓點控制點，可以獨立拖曳調整陰影的位置，不會動到商品本體
- **右欄**：品牌（僅供資料庫比對排序用）、背景色、商品影子（光源角度四選一：
  左/中/右/關）、重設商品位置/縮放/陰影位移按鈕

素材太多不好選的時候，可以點「瀏覽資料庫（圖示選擇）」，右欄會原地切換成
縮圖選擇畫面（滑出/滑回都在右欄自己的範圍內，popup本身的位置/大小完全
不會變動，兩個畫面也不會同時疊在畫面上）；點縮圖直接套用，或點右上角
關閉切回設定畫面。

## 商品影子的重要設計細節

- 商品本體的繪製**完全跟陰影開關脫鉤**——不管有沒有開陰影，商品都是同一份
  邏輯畫出來的，切換光源角度/開關陰影**不會**讓商品的位置跳動
- 陰影有自己獨立的X/Y位移（灰色控制點拖曳），跟商品本體的位置/縮放是兩件
  互不影響的事情
- 選取框/縮放基準只看圖片裡「真正有色」的範圍——抓自 ShadowPlugin 本來就會
  算的透明留白比例（給陰影貼地位置用的同一份資料），不是整張PNG含透明留白
  的完整尺寸

## 為什麼這樣分
跟你之前的 shopee-home 專案同一個精神：**新增功能＝加檔案，不是改檔案**。
要加新的版位元素，在 `modules/` 加一支新檔案，寫好 `buildDom()`（畫面怎麼
編輯）跟 `drawExport()`（匯出時怎麼畫），再去 `core.js` 的
`buildSlotContent()` / `renderBannerToCanvas()` 各加一行呼叫（注意疊放順序：
商品圖一定要排在CTA前面，CTA才會蓋在商品上面），跟 `editor.html` 加一行
`<script src="modules/新檔案.js">`。其他模組完全不用動。

## LOGO／商品資料庫怎麼建檔

📄 詳細的歸檔規則（檔名怎麼取、放哪個資料夾、尺寸規格、常見問題）都整理在
**`ASSET-GUIDE.md`**，這裡只列重點：

1. 圖檔丟進 `system-elements/festival/`、`system-elements/site-wide-sale/`、
   `system-elements/common/`（LOGO），或 `artwork/site-wide-sale/`、
   `artwork/common/`（商品/曝品）
2. 到 `data/asset-library.json` 對應分類補一筆，LOGO範例：
   ```json
   { "id": "brand_x_logo", "brand": "品牌X", "name": "品牌X主LOGO", "type": "logo", "path": "system-elements/common/brand-x.png" }
   ```
   商品範例：
   ```json
   { "id": "product_x", "brand": "品牌X", "name": "商品X去背圖", "path": "artwork/common/product-x.png" }
   ```
3. 重新整理頁面，放大編輯任一版位，對應區塊的「瀏覽資料庫（圖示選擇）」或
   下拉選單就會列出來（依分類分組，且會優先把品牌名稱對得上的排在前面）

之後如果要換成真的後端 API，只要改 `js/asset-library.js` 裡 `load()` 那個
fetch 的目標（換成你的 API），回傳格式維持
`{ systemElements:{catKey:{label,items:[...]}}, artwork:{catKey:{label,items:[...]}} }`
就好，其他檔案完全不用動。
